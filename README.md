# Shift-numbered-letter-ordered-files
This is a python script which provides a utility to mass rename files based on their numbering/lettering

Python 3 code to shunt multiple files in a directory or folder
1-example.txt --> 1-example.txt
1a-example.jpeg --> 1b-example.jpeg
for all the matching files

Usage: python rename.py <pushStart> <directory = .>
